# PDF Intelligence —&#x20;

A PDF Question Answering application built using **Streamlit, LangChain, ChromaDB, Hugging Face Embeddings, and Groq**. Upload a PDF and ask questions to get AI-generated answers based on its content.

## Features

- Upload and process PDF documents
- Semantic search using vector embeddings
- AI-powered question answering
- Dark-themed Streamlit interface

## Tech Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- Hugging Face Sentence Transformers
- Groq API

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Configure your `GROQ_API_KEY` environment variable before running the application.

## Deployment

Deployed using [Streamlit Community Cloud](https://share.streamlit.io/).
